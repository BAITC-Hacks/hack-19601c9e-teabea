# Сценарий демо на 5 минут

1. Из корня запустить `python run.py` и открыть `http://127.0.0.1:8000`. Показать период, 2 248 узлов, 3 119 рёбер и доступные CSV.
2. В top-20 открыть первый узел: показать роль, `role_score`, независимый `priority_score`, входящий/исходящий оборот и explanation.
3. Найти программно выбранный boundary-узел из результата: взять первый узел с `truncated_by_depth=true`. Показать предупреждение «исходящие за 4-м коленом не видны».
4. Найти первый изолят из результата: взять узел с `in_deg=0` и `out_deg=0`. Показать, что карточка, кластер и evidence существуют, даже если у него нет рёбер.
5. Переключить `1 шаг`/`2 шага`/`Вся сеть`, цвет `Роли`/`Кластеры`, затем открыть вкладку кластеров и перейти по строке кластера.
6. Скачать `nodes_roles.csv`, `clusters.csv`, `top_nodes.csv`. Завершить оговоркой: роли являются структурными гипотезами, а не выводом о виновности.

Конкретные gid не зашиваются в алгоритм: демонстрационные узлы выбираются из актуального `out/nodes_roles.csv` и snapshot после расчёта.
