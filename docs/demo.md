# Демо: 5 минут

Сценарий использует gid, выбранные программно из текущего расчёта, а не из классификатора.
Перед показом установите зависимости. Запуск: `.venv\Scripts\python.exe run.py`.
Откройте http://127.0.0.1:8501. Подготовьте второе окно с README и CSV.

| Время | Действие и объяснение |
|---|---|
| 0:00 | Аналитик получает сеть наблюдаемых переводов и объяснимый приоритет проверки. Роли — гипотезы. |
| 0:30 | Запустите run.py. Измеренные полные прогоны parquet → CSV: 10.007 и 8.891 с. Покажите период и фактические размеры. |
| 1:15 | Откройте глобальный топ и нажмите «Показать на графе» для 100000005910114100. Перейдите в «Граф и карточка», прочитайте evidence и четыре вклада приоритета. |
| 2:15 | Найдите консолидацию 100000008346837100, затем транзит 100000004707703100. Сравните наблюдаемый вход и выход, не делайте вывод о движении тех же денег. |
| 3:00 | Поиск произвольного 100000004261340100. Выберите два шага. Покажите изолят 100000000456947100 — одна точка и отсутствие данных для роли. |
| 3:40 | Найдите boundary 100000000018102100. Прочитайте предупреждение depth=4. Покажите фильтры, пустой список ролей, сброс, режим всей сети и выбор кластера. |
| 4:20 | Скачайте три CSV. Покажите архитектуру, воспроизводимость и план масштабирования. |

Клик по графу открывает подробности внутри iframe. Карточка Streamlit выбирается поиском или топом.
Проверка сценария через AppTest отражена в verification.md; визуальная браузерная проверка отдельно не подтверждена.
