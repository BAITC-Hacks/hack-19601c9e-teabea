# Загрузка данных и движущийся граф

## Запуск без повторного пересчёта примера

```powershell
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe -m streamlit run app.py --server.address 127.0.0.1 --server.port 8502 -- --data out_local --edges data/edges_local.csv
```

Откройте http://127.0.0.1:8502. Если результаты примера лежат в out, замените аргументы на `--data out --edges data/edges.csv`. При отсутствии выгрузок всё равно можно переключиться на собственные данные. В окружении разработки используется `.venv-ui` вместо `.venv`.

## Собственный набор

Выберите «Свои данные» и загрузите nodes, edges, transactions. Можно смешивать CSV (UTF-8, разделитель запятая) и Parquet. Имена файлов произвольные: назначение определяется полем загрузки. Схемы:

- nodes: gid, depth, is_seed.
- edges: src, dst, sum_kzt, n_tx, depth.
- transactions: src, dst, date, sum_kzt.

Идентификаторы — неотрицательные десятичные int64 без дробной части, экспоненты и ведущих нулей. В Parquet допустим int64 или строка, float отвергается из-за потери точности. Boolean: true/false или 1/0. Суммы конечны и неотрицательны, n_tx положительный. Даты предпочтительно ISO. Проверяются дубликаты, ссылки, совпадение пар, суммы с atol=0.01/rtol=1e-12 и точное число транзакций.

Предпросмотр содержит первые 20 строк; gid показаны строками. Лимиты интерактивной версии: 50 МБ на файл, 100 000 строк на таблицу, 10 000 узлов для точного расчёта. Большие наборы требуют отдельной оптимизации расчётной части.

Глубина обхода, порог суммы и охват переводов по умолчанию неизвестны. Максимальный depth в таблице не считается границей наблюдения. При неизвестной глубине boundary не назначается, а terminal консервативно отключён. Вклад достижимости seed считается по наблюдаемому графу без искусственного лимита 4. При заданной глубине она используется для валидации, достижимости и boundary. Полнота входящих seed сохраняется отдельно. Правила и веса ролей остаются общими, пример хакатона сохраняет прежние параметры.

«Рассчитать новый граф» вызывает настоящие функции pipeline в фоновом потоке. Во время работы повторная кнопка и смена входа заблокированы. Пока новый вход не рассчитан, старые показатели и загрузки скрыты. При ошибке результат не активируется. Каждому успешному расчёту соответствует отдельная папка `.user_runs/dataset-*`; исходные данные организаторов не перезаписываются. Для этих папок нет автоматической очистки.

Три download_button отдают CSV активного набора целиком. «Открыть пример хакатона» возвращает исходный источник и сбрасывает выбор/фильтры.

## Движение

Круглые узлы имеют цвета ролей; seed обозначен золотой обводкой, boundary — пунктирной. Перетаскивание узла временно включает физику, соседи реагируют. Если до перетаскивания была пауза, она возвращается после отпускания. Колёсико масштабирует, перетаскивание фона перемещает камеру.

«Движение / Пауза» управляет физикой. «Перестроить граф» плавно переводит узлы к новому начальному размещению за 600 мс и запускает раскладку, сохраняя выбранный gid. «Вписать в окно» меняет только камеру. «Показать весь граф» в приложении снимает фильтры и показывает все узлы. Полная сеть или подграф более 150 узлов останавливаются после стабилизации либо через 6 секунд. Малый подграф затухает естественно. Открытие подробностей узла ставит движение на паузу.

Шаблон использует только встроенные ресурсы PyVis, без CDN. Сетка, карточки и отступы заданы в ui/style.css. При ширине ≤1100 px колонки перестраиваются вертикально; таблицы прокручиваются внутри блока.

## Проверки

Итоговый прогон: **25 passed in 20.47s** — 6 проверок pipeline, 5 прежнего UI, 3 launcher и 11 загрузки/пересчёта. Обновлённое приложение запущено на 127.0.0.1:8504, `/_stcore/health` вернул HTTP 200 и `ok`.

Streamlit AppTest использует реальные file_uploader для смешанного CSV/Parquet-набора с большими gid и depth=6, запускает настоящий pipeline, проверяет поиск, топ, смену источника, скрытие устаревшего результата и байты загрузок. Отдельно проверены ошибки схемы, int64 overflow, float gid, boolean, ссылки, суммы и n_tx. SHA-256 исходных parquet до и после совпадает.

Браузерный инструмент вернул пустой список браузеров. Визуальная проверка 1280/1440/1920 px, фактическое перетаскивание мышью и оценка плавности не выполнены. Автоматические тесты и проверка HTML не заменяют эти проверки.
