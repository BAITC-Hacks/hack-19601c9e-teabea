# Backend: граф денег

## Запуск в Windows

Из корня репозитория:

```powershell
python -m pip install -r requirements.txt
python -m backend.app.pipeline --data data --out out
python -m uvicorn backend.app.main:app --host 127.0.0.1 --port 8000
```

Путь к `data` и `out` разрешается относительно корня репозитория, поэтому запуск не зависит от текущей папки. Пайплайн сначала пишет во временный каталог и публикует `out` только после успешного snapshot.

## Что рассчитано

Проверяются колонки, типы, уникальность `gid` и пар рёбер, ссылки, depth, даты, конечность сумм, а также точное `n_tx` и суммы транзакций по `(src, dst)`. Для float используется `atol=0.01 KZT` и `rtol=1e-9`.

Граф направленный и содержит все nodes, включая изоляты. Для кластеризации строится неориентированная проекция, встречные суммы складываются. Louvain использует `seed=42`, после чего сообщества сортируются и получают канонические номера.

Роли проверяются в порядке `coordinator -> distributor -> consolidator -> transit -> terminal -> peripheral`:

- `coordinator`: reach от минимум двух seed, betweenness не ниже 90-го перцентиля положительных значений и связи минимум с двумя другими сообществами;
- `distributor`: `out_deg >= 10`;
- `consolidator`: `in_deg >= 3` и положительный наблюдаемый вход;
- `transit`: не seed, не depth-4 boundary, есть вход и выход, `pass_through` в `[0.8, 1.2]`;
- `terminal`: не seed, `depth < 4`, есть вход и нет выхода;
- `peripheral`: остальные узлы, включая изоляты.

`role_score` - детерминированная сила поддержки гипотезы, не вероятность. `priority_score` рассчитывается независимо:

`0.30 P(in_deg) + 0.20 P(in_kzt) + 0.20 P(seed_reach_count) + 0.15 P(betweenness) + 0.15 P(out_deg)`.

`P` - percentile rank только положительных значений; нулевой признак получает 0, равные значения получают одинаковый rank. `gid` используется только как численный стабильный tie-break. Исходящие за depth 4 не наблюдаются, а входящие seed могут быть неполными; эти ограничения попадают в evidence/explanation.

## API

Контрактные маршруты находятся под `/api`: `/summary`, `/nodes`, `/nodes/{gid}`, `/graph`, `/clusters`, `/top`, `/exports/{filename}`. `/health` доступен до расчёта и сообщает `data_ready=false`; остальные данные дают 503 до появления snapshot. Download whitelist ограничен тремя CSV.

## Ограничения и масштабирование

Это структурные гипотезы без ground truth, не доказательства виновности и не полный баланс денег. Суммы могут считать движение одних средств несколько раз. Даты дневные, поэтому временная близость не доказывает транзит тех же средств. Betweenness приближённая и использует ограниченное число источников.

При росте к примерно миллиону узлов следует заменить Python-объекты NetworkX на CSR/igraph, оставить колоночные агрегаты Arrow/Polars, считать центральность приближённо и отдавать браузеру только подграфы/агрегированные слои, а не весь граф.
