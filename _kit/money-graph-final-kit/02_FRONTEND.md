# Полный промпт для фронтенда

Ты дорабатываешь существующий интерфейс «Граф денег» в VS Code. Прочитай AUDIT.md, 04_CONTRACT.md, app.py и viewer_original.html. Создай рабочий интерфейс на Streamlit + PyVis. Пайплайн делает другой разработчик; роли и приоритеты бери из его CSV, не пересчитывай и не подменяй их. Не вводи React, FastAPI, авторизацию или внешние сервисы.

## Исправления до оформления

1. Загружай узловые метрики из node_metrics_full.csv, обязательные выгрузки — из out/. Проверь согласованность gid, наличие файлов/полей. При отсутствии расчёта покажи точную CLI-команду и останови отрисовку с понятным сообщением. Не используй fallback на вымышленные данные.
2. В pandas идентификаторы читать строками. PyVis nodes/edges и любой JSON — только string gid/src/dst, включая выбор и поиск. Никаких int(gid) при передаче графу, float или parseInt. Все 2248 идентификатора больше JS-safe integer.
3. Сохраняй выбранный gid и режим графа в st.session_state. Поиск, выбор из топа и «Весь граф» должны реально менять состояние до построения графа. Устрани ключ _focus, который сейчас только записывается. Используй callbacks или корректный rerun, исключи бесконечные циклы.
4. Режим полного графа не должен пропадать при следующем изменении фильтра. Пустой список выбранных ролей означает пустой граф. Должна быть явная кнопка сброса.
5. Удали запись /tmp/_graph.html. Встраивай HTML из памяти. Настрой локальные/inline ресурсы PyVis и проверь сгенерированный HTML: не должно быть внешних script/link к CDN. Если стандартная генерация добавляет Bootstrap CDN, отключи ненужный шаблонный ресурс или сделай локальный шаблон. Одного параметра cdn_resources без проверки недостаточно.
6. Добавь скачивание трёх настоящих CSV через download_button. Фильтры не меняют выгрузки.
7. Кэш учитывает изменение результатов (mtime/hash файлов), чтобы после пересчёта UI не показывал старые данные. Добавь обновление результатов. Источник по умолчанию определяется от корня проекта.

## Экран для аналитика

Русский интерфейс, аккуратный тёмный графитовый фон графа, читаемые карточки и таблицы, бирюзовый акцент, без декоративных экранов. Цель: по названному gid за минуту показать связи, роль, численные причины и ограничения.

Верх: название, период из metadata, метрики фактического датасета (узлы, рёбра, транзакции, кластеры, оборот по рёбрам), время последнего расчёта если оно сохранено. Не зашивай числа из исходного README. Название оборота поясняет, что это сумма переводов, не уникальные деньги.

Сайдбар: поиск точного gid, режим «Топ + окружение / Выбранный узел / Вся сеть», фильтры роли, кластера, depth, seed, минимальной суммы ребра. Для выбранного узла: 1 или 2 шага. Соседство находить по обеим сторонам связности, стрелки сохранять src→dst. Кнопки «Сбросить фильтры» и «Обновить данные».

Граф: направления стрелками; цвет по ролям либо кластерам; легенда; отдельная обводка seed; обозначение boundary. Размер узла ограничить и пояснить, например priority_score. Подписи не рисовать для всех 2248 одновременно, полный gid доступен в карточке/tooltip. Количество видимых узлов и рёбер показывать честно. На полный граф предусмотреть ограничение времени физической раскладки и остановку стабилизации; не скрывать узлы без уведомления. Изолированный узел отображается точкой и доступен поиском.

Справа или под графом: карточка ВЫБРАННОГО gid. Роль по-русски, role_score с подписью «поддержка гипотезы», priority_score, кластер, depth, seed; вход/выход по числу контрагентов, сумме и числу транзакций; evidence, полное explanation и вклад признаков в приоритет. Pass-through без данных — «н/д». У seed и boundary заметное предупреждение. Не называть observed разницу сумм балансом.

PyVis внутри iframe сам по себе не возвращает выбор в Python. Минимальный обязательный выбор карточки обеспечь поиском и рабочими кнопками топа/таблицы. При клике на узел графа должна быть хотя бы реальная подробная подсказка внутри графа. Если обещаешь обновление Streamlit-карточки кликом, реализуй настоящий мост событий, а не фиктивную реакцию.

Топ-20: ранг, полный gid, роль, приоритет, why и рабочая кнопка перехода. При выборе из топа/поиске сбрось конфликтующие фильтры и сообщи об этом. Топ глобальный, подпиши это. Неизвестный gid — предупреждение без молчаливого перехода на другой узел.

Вкладка кластеров: размер, seed, внутренний оборот, hypothesis и переход к графу выбранного кластера. Вкладка ограничений: depth=4, неполный вход, порог 5000, внутрибанковские переводы, нет ground truth. Предупреждения привязывай к данным, не перегружай экран текстом.

Русские подписи: consolidator «Консолидация»; transit «Транзит»; distributor «Распределение»; terminal «Возможный конечный получатель»; coordinator «Координация — гипотеза»; peripheral «Недостаточно выраженных признаков». Машинные enum в CSV не менять.

## Проверки

requirements-ui.txt — проверенные зависимости Streamlit/PyVis. Запусти экран, а не только py_compile. Проверь длинный gid без изменения, поиск изолята, переход из топа, сохранение режима полного графа, пустой фильтр, смену кластера, обновление после пересчёта и скачивание всех CSV. Убедись, что граф работает без CDN после установки зависимостей. Проверь экран ноутбука 1280×720. Новые обязательные колонки при отсутствии должны давать инструкцию пересчёта, не выдуманные значения.

Если браузер или сервер недоступен, раздели выполненные проверки и непроверенное. В финале дай рабочую команду Streamlit, список файлов и подтверждённых сценариев. viewer_original.html оставь резервным исходником; не трать время на поддержку двух интерфейсов, пока главный не готов.
